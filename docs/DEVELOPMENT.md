# Development Guide

**Project:** AllAffiliate_Agent

**Version:** 0.3

**Status:** Active

**Last Updated:** 2026-07-16

**Owner:** AllAffiliate_Agent Team

---

# الهدف

يوضح هذا المستند قواعد تطوير مشروع AllAffiliate_Agent، ويعتبر المرجع الرسمي لأسلوب كتابة الكود، وتنظيم الملفات، وآلية التطوير.

---

# القواعد العامة

- اللغة الأساسية للمشروع: العربية.
- لغة البرمجة: Python.
- جميع أسماء الملفات والمجلدات باللغة الإنجليزية.
- جميع أسماء Classes باللغة الإنجليزية.
- جميع أسماء Functions باللغة الإنجليزية.
- جميع أسماء المتغيرات باللغة الإنجليزية.
- التعليقات داخل الكود باللغة العربية عند الحاجة.

---

# قواعد المعمارية

- جميع الطلبات تمثل Task.
- جميع العمليات تعيد Result.
- جميع Agents يرثون من BaseAgent.
- جميع Agents مستقلة.
- جميع Services مستقلة.
- جميع Tools مستقلة.
- يمنع استخدام if/elif الطويل داخل TaskRouter.
- يمنع وصول Agent مباشرة إلى نظام التشغيل.
- يمنع وصول Tool إلى Agent أو User.

---

# قواعد إنشاء الملفات

كل ملف جديد يجب أن يوثق وفق الترتيب التالي:

1. اسم الملف.
2. الهدف.
3. علاقته بالمشروع.
4. المحتوى الكامل.
5. الاختبار.
6. النتيجة المتوقعة.
7. الحالة.

---

# قواعد الاختبار

- لا يعتبر أي ملف مكتملاً قبل اختباره.
- يجب توثيق طريقة الاختبار.
- يجب توثيق النتيجة المتوقعة.
- يجب إصلاح جميع الأخطاء قبل الانتقال للملف التالي.

---

# قواعد التوثيق

جميع ملفات docs يجب أن تحتوي على:

- Project
- Version
- Status
- Last Updated
- Owner

ويجب تحديثها عند كل تعديل.

---

# قواعد Git

- كل ميزة جديدة في Commit مستقل.
- كتابة رسائل Commit واضحة.
- عدم دمج أكثر من ميزة في Commit واحد.

---

# قواعد التطوير

- لا نعيد كتابة الملفات إلا عند الحاجة.
- يتم تطوير الملفات تدريجياً.
- الحفاظ على التوافق مع الإصدارات السابقة قدر الإمكان.
- أي قرار معماري جديد يجب توثيقه.
- لا يتم الانتقال إلى الملف التالي قبل اعتماد الملف الحالي.
