# الهدف

يوضح هذا المستند قواعد تطوير مشروع AllAffiliate_Agent، ويعتبر المرجع الرسمي لأسلوب كتابة الكود، وتنظيم الملفات، وآلية التطوير.

---

# القواعد العامة

- اللغة الأساسية للمشروع: العربية.
- لغة البرمجة: Python.
- جميع أسماء الملفات والمجلدات باللغة الإنجليزية.
- جميع أسماء Classes باللغة الإنجليزية.
- جميع أسماء Functions باللغة الإنجليزية.
- جميع أسماء المتغيرات باللغة الإنجليزية.
- التعليقات داخل الكود باللغة العربية عند الحاجة.

---

# قواعد المعمارية

- جميع الطلبات تمثل Task.
- جميع العمليات تعيد Result.
- جميع Agents يرثون من BaseAgent.
- جميع Agents مستقلة.
- جميع Services مستقلة.
- جميع Tools مستقلة.
- يمنع استخدام if/elif الطويل داخل TaskRouter.
- يمنع وصول Agent مباشرة إلى نظام التشغيل.
- يمنع وصول Tool إلى Agent أو User.

---

# قواعد إنشاء الملفات

كل ملف جديد يجب أن يوثق وفق الترتيب التالي:

1. اسم الملف.
2. الهدف.
3. علاقته بالمشروع.
4. المحتوى الكامل.
5. الاختبار.
6. النتيجة المتوقعة.
7. الحالة.

---

# قواعد الاختبار

- لا يعتبر أي ملف مكتملاً قبل اختباره.
- يجب توثيق طريقة الاختبار.
- يجب توثيق النتيجة المتوقعة.
- يجب إصلاح جميع الأخطاء قبل الانتقال للملف التالي.

---

# قواعد التوثيق

جميع ملفات docs يجب أن تحتوي على:

# قواعد Git

- كل ميزة جديدة في Commit مستقل.
- كتابة رسائل Commit واضحة.
- عدم دمج أكثر من ميزة في Commit واحد.

---

# قواعد التطوير

- لا نعيد كتابة الملفات إلا عند الحاجة.
- يتم تطوير الملفات تدريجياً.
- الحفاظ على التوافق مع الإصدارات السابقة قدر الإمكان.
- أي قرار معماري جديد يجب توثيقه.
- لا يتم الانتقال إلى الملف التالي قبل اعتماد الملف الحالي.

## سجل التطوير — 13 سبتمبر 2026

### البنية التحتية
تم تحديث Docker Desktop إلى 4.90.0، والتحقق من Docker Engine بالإصدار 29.7.2.

تم اختبار Docker Registry بواسطة docker pull hello-world ونجح التنزيل.

### التحقق من المشروع
تم اختبار AllAffiliate_Agent باستخدام Python 3.12.0 والبيئة الافتراضية myenv.

لا يستخدم المشروع حاليًا Docker Compose ولا يحتوي على Dockerfile، لذلك تم اختبار Docker بشكل مستقل.

### المكونات التي تم اختبارها
- Result
- FileTools
- TerminalTools
- PythonTools

### القرار الحالي
لن يتم تعديل الكود العامل قبل تحليل حالات False وحالة Cleanup وتحديد ما إذا كانت نتائج متوقعة أم أخطاء فعلية.


## التحقق النهائي - 14 سبتمبر 2026

تمت إعادة اختبار المكونات الأساسية باستخدام Python الموجود داخل myenv بشكل صريح.

تم التأكد من أن نتائج الاختبارات مطابقة للنتائج السابقة، وأن حالات False الظاهرة هي سلوك مقصود ومتوقع.

لم يتم اكتشاف عيب فعلي في Result أو FileTools أو TerminalTools أو PythonTools من خلال الاختبارات الحالية.

### القرار
عدم تعديل المكونات المختبرة، والانتقال إلى مراجعة طبقات core/ وservices/.
